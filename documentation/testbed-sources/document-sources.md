# Document Testbed Source Pack

## Goal

Prepare two document-oriented source sets that stress boundary and structure questions without domain lock-in.

## Source Set A: Narrative Baseline

* intake id: doc-source-001
* profile target: document
* purpose: establish baseline document behavior with minimal structure

Suggested files:

* doc-source-001/source.txt or source.pdf
* doc-source-001/metadata-notes.md

Required characteristics:

* clear title and author signals
* explicit version or edition mention if available
* no major embedded media dependency

Question coverage:

* edition/version relationship behavior
* baseline document-profile fit

## Source Set B: Embedded-Media or Rich Subdivision

* intake id: doc-source-002
* profile target: document
* purpose: test subdivision modeling and document-media boundary

Suggested files:

* doc-source-002/source.pdf
* doc-source-002/embedded-media-index.md
* doc-source-002/metadata-notes.md

Required characteristics:

* at least one meaningful embedded image/diagram/table
* clear internal subdivision signals (sections, chapters, clauses, or headings)
* enough structure to compare lightweight vs explicit subdivision representation

Question coverage:

* subdivision representation need
* document versus media/composite boundary

## Intake Completion Checklist

* source location recorded
* license/usage status recorded
* normalization steps recorded
* known limitations recorded
* baseline readiness set in documentation/testbed-source-intake.md
