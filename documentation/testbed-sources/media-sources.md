# Media Testbed Source Pack

## Goal

Prepare two media source sets that test descriptive provenance and segmentation needs.

## Source Set A: Image or Diagram Collection

* intake id: media-source-001
* profile target: media
* purpose: baseline image-oriented media behavior

Suggested files:

* media-source-001/image-01.png (or jpg)
* media-source-001/image-02.png (or jpg)
* media-source-001/descriptions.md

Required characteristics:

* at least one technical asset property available (format, dimensions)
* at least one human-written description
* optional generated description to compare provenance handling

Question coverage:

* technical vs interpretive placement
* generated vs curated description distinction

## Source Set B: Audio or Video Segmentable Source

* intake id: media-source-002
* profile target: media
* purpose: test segment/time or frame-region semantics

Suggested files:

* media-source-002/source.mp3 or source.mp4
* media-source-002/transcript-or-captions.md
* media-source-002/segment-index.md

Required characteristics:

* at least one transcript/caption fragment
* at least one meaningful segment reference (time range)
* optional generated summary with review status

Question coverage:

* captions/transcripts representation
* segment or region representation
* generated-description provenance

## Intake Completion Checklist

* source location recorded
* license/usage status recorded
* normalization steps recorded
* known limitations recorded
* baseline readiness set in documentation/testbed-source-intake.md
